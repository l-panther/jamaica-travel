# Jamaica Website

## Description
This project is a static website that showcases Jamaica, highlighting its culture, attractions, and key information for visitors. It provides users with an overview of popular parishes.

## Features
- Information about Jamaica’s culture and heritage  
- Highlights of popular parishes with brief description  
- Responsive and user-friendly interface  
- Clean and accessible design  

## Installation
No installation is required.

## Usage
To view the website:

1. Upload all project files to a web server and navigate to the root directory, **or**  
2. Open the `index.html` file in a web browser  

## Configuration
No configuration is required. Content can be updated directly within the source files.

## Technologies
- HTML  
- CSS  
- JavaScript
